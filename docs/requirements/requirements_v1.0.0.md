# 書籍管理システム 要件定義書

**バージョン**: v1.0.0  
**作成日**: 2026/01/27

## 1. プロジェクト概要
本プロジェクトは、既存の「人事管理システム（テスト用）」のソースコードをベースに、本番用システムである「書籍管理システム」へ移行・刷新することを目的とする。
基本的なアーキテクチャ（Vue3 + Django）及びCRUD機能は維持しつつ、管理対象を「社員」から「書籍」に変更する。

## 2. 目的
- 書籍情報の効率的な管理（登録、検索、編集、削除）を実現する。
- 既存資産（人事管理システム）を最大限流用し、短期間での開発・移行を行う。

## 3. 機能要件

### 3.1 書籍管理機能
| 機能ID | 機能名 | 概要 | 備考 |
| --- | --- | --- | --- |
| FUNC-001 | 書籍一覧表示 | 登録されている書籍の一覧を表示する。 | キーワード検索機能を含む（タイトル等） |
| FUNC-002 | 書籍詳細表示 | 書籍の詳細情報を表示する。 | |
| FUNC-003 | 書籍新規登録 | 新しい書籍情報を登録する。 | |
| FUNC-004 | 書籍情報編集 | 既存の書籍情報を更新する。 | |
| FUNC-005 | 書籍削除 | 書籍情報を削除する。 | |

### 3.2 データ項目定義（社員管理との対応マッピング）
既存の社員モデル（Employee）を以下の通り書籍モデル（Book）に読み替える。

| 人事管理項目 (Employee) | 書籍管理項目 (Book) | データ型 | 必須 | 備考 |
| --- | --- | --- | --- | --- |
| name (氏名) | **title** (書籍名) | String | ○ | |
| password (パスワード) | **author** (著者名) | String | ○ | ※パスワード項目を著者名として流用 |
| salary (給与) | **price** (価格) | Integer | ○ | |
| location_name (勤務地) | **publisher** (出版社) | String | - | |
| image_path (画像パス) | **image_path** (画像パス) | String | - | 表紙画像用 |

## 4. 非機能要件
- **開発言語/フレームワーク**:
    - Frontend: Vue 3 (Composition API)
    - Backend: Python (Django 4.x + Django REST framework)
- **データベース**: SQLite (開発段階)
- **UI/UX**: 既存の人事管理システムの操作感を踏襲する。

## 5. 前提事項
- ソースコードは `globalbooks_Vue3-Django` リポジトリで管理する。
- `feature/book-management-init` ブランチにて開発を行う。
