# 書籍管理システム 要件定義書

**バージョン**: v1.1.0  
**作成日**: 2026/01/27  
**更新日**: 2026/11/04

## 1. プロジェクト概要
Vue 3とDjangoで、書籍の登録・検索・編集・削除ができるWebアプリを作る。

## 2. 目的
- 書籍情報のデジタル化と一元管理。
- 書籍の検索・確認・更新の効率化。

## 3. 機能要件

### 3.1 書籍管理機能
| 機能ID | 機能名 | 概要 | 備考 |
| --- | --- | --- | --- |
| FUNC-001 | 書籍一覧表示 | 登録されている書籍の一覧を表示する。 | 書籍名でのキーワード検索が可能 |
| FUNC-002 | 書籍詳細表示 | 書籍の詳細情報を表示する。 | |
| FUNC-003 | 書籍新規登録 | 新しい書籍情報を登録する。 | |
| FUNC-004 | 書籍情報編集 | 登録済みの書籍情報を変更する。 | |
| FUNC-005 | 書籍削除 | 書籍情報を削除する。 | |

### 3.2 データ項目定義
書籍情報として以下の項目を管理する。

| 項目名 | 論理名 | データ型 | 必須 | 備考 |
| --- | --- | --- | --- | --- |
| title | 書籍名 | String | ○ | 最大255文字 |
| author | 著者名 | String | ○ | 最大255文字 |
| price | 価格 | Integer | ○ | 1以上の整数。登録・編集・APIで共通 |
| publisher | 出版社 | String | - | 最大255文字 |
| image_path | 画像パス | String | - | 最大255文字。`/images/1.png` 形式のパス、またはhttp/httpsの画像URL |
| like_count | いいね数 | Integer | 自動設定 | 追加機能専用。基本機能では使わない。列だけ最初から用意し、初期値0。フォーム入力は不要 |

**入力・表示のルール**

| 状況 | 画面での扱い |
| --- | --- |
| タイトル・著者名が空白のみ | 入力不備として扱う |
| 画像パスが空文字・null | 「画像なし」と表示 |
| 検索結果が0件 | 該当なしの案内を表示 |
| APIでエラーが発生 | 画面内にメッセージを表示 |

### 3.3 オプション機能（任意課題）

基本のCRUD・検索を完成させた後、好きな機能を選ぶ。未実装の追加機能があっても基本課題は完成とする。

| 機能ID | 機能 | 目標 |
| --- | --- | --- |
| OPT-001 | 並び替えボタン | 価格順・書籍名順など、複数の順序で一覧・検索結果を表示する |
| OPT-002 | いいね | 押すたびに1増やして保存する。ログイン不要で何度でも押せる |
| OPT-003 | 画像ファイル添付 | Vueで選んだ画像をDjangoに保存し、書籍の表紙として表示する |

業務用テーブルは `books` の1つ。画面例は基本設計書の第7章に掲載する。表示や実装の細部は受講者に任せる。
