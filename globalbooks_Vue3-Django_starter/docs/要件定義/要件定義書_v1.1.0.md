# 書籍管理システム 要件定義書

**バージョン**: v1.1.0  
**作成日**: 2026/01/27  
**更新日**: 2026/11/04

## 1. プロジェクト概要
本プロジェクトは、書籍情報を一元管理し、登録・検索・編集・削除を効率的に行える「書籍管理システム」を新規開発することを目的とする。
直感的な操作性を重視し、モダンなWeb技術（Vue 3 + Django）を用いて構築する。

## 2. 目的
- 書籍情報のデジタル化と一元管理。
- 書籍の検索、在庫確認（将来拡張）等の業務効率化。

## 3. 機能要件

### 3.1 書籍管理機能
| 機能ID | 機能名 | 概要 | 備考 |
| --- | --- | --- | --- |
| FUNC-001 | 書籍一覧表示 | 登録されている書籍の一覧を表示する。 | 書籍名でのキーワード検索が可能 |
| FUNC-002 | 書籍詳細表示 | 書籍の詳細情報を表示する。 | |
| FUNC-003 | 書籍新規登録 | 新しい書籍情報を登録する。 | |
| FUNC-004 | 書籍情報編集 | 登録済みの書籍情報を変更する。 | |
| FUNC-005 | 書籍削除 | 書籍情報を削除する。 | |

### 3.2 データ項目定義
書籍情報として以下の項目を管理する。

| 項目名 | 論理名 | データ型 | 必須 | 備考 |
| --- | --- | --- | --- | --- |
| title | 書籍名 | String | ○ | 最大255文字 |
| author | 著者名 | String | ○ | 最大255文字 |
| price | 価格 | Integer | ○ | 1以上の整数。登録・編集・APIで共通 |
| publisher | 出版社 | String | - | 最大255文字 |
| image_path | 画像パス | String | - | 最大255文字。`/images/1.png` 形式のパス、またはhttp/httpsの画像URL |
| like_count | いいね数 | Integer | 自動設定 | 追加機能専用。基本機能では使わない。列だけ最初から用意し、初期値0。フォーム入力は不要 |

タイトル・著者名は空白のみの入力を認めない。画像パスの空文字・nullは「画像なし」と表示する。検索結果が0件の場合は案内文を表示する。APIエラーは画面内に表示する。

### 3.3 オプション機能（任意課題）

基本のCRUD・検索を完成させた後、次の3つから選択して実装する。オプション未実装でも基本課題は完成とする。

- OPT-001：ID・価格・書籍名・いいね数による並び替えボタン。検索結果にも適用する。
- OPT-002：書籍ごとのいいね。押すたびに1増やし、回数を保存する。ユーザー管理・回数制限・取り消しは設けない。
- OPT-003：JPEG・PNG画像のファイル添付。Vueで選択・送信し、Djangoで保存する。保存URLは既存の `image_path` を使用する。

アプリケーションのテーブルは `books` の1つとする。詳細・完成条件は[基本設計書 第7章「追加機能」](../基本設計/基本設計書_v1.1.0.md#7-追加機能)を参照する。

## 4. 非機能要件
- **開発言語/フレームワーク**:
    - Frontend: Vue 3 (Composition API, TypeScript)
    - Backend: Python (Django 5.2系 + Django REST Framework 3.16.1)
- **データベース**: SQLite (開発段階)
- **UI/UX**: シンプルで直感的なデザインを採用する。
- **実装方針**: 学習済みの参考用コードの書き方に合わせる。Vueの各画面で `ref`、`onMounted`、Axios、`try/catch`、Vue Routerを用いる。

## 5. 運用想定
- ローカル環境での演習用とする。公開運用の認証・権限制御は演習範囲外とする。
